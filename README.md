# Project Kajana

Project Kajana is a tech demo for a Survival Game set in the deepest of winters. The game was originally an entry for Pirate Software - Game Jam 14.
Due to lack of motivation, the game is now abandoned, and functions as a open-source base for a survival game that anyone is free to use.

## Where are the assets?

To prevent generative AI models from scraping off my handmade assets, I opted to remove all of them from this public repository.

Game developement is much more than just writing code. Artists are equally important for the process of making a game, and to do my part in preventing soulless AI replacing my artist friends, I want to keep all assets made by me, or my colleques away from public repositories. Support your local artists. Support Game Making. <3
